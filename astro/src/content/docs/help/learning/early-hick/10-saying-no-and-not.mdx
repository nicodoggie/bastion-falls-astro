## What You'll Learn

This lesson teaches three ways Early Hick handles negative meaning:

- `mope`, the ordinary answer for "no";
- `mo-`, the prefix that means "not";
- `pe!`, a sharper refusal word used in limited situations.

## Saying No with `mope`

Use `mope` when the answer to a yes/no question is simply "no."

```txt
'athid 'al-es barak'er?
IS.IT.TRUE person-MAIN walk-ACTION
"Does the person walk?"

mope
no
"No."
```

`mope` answers the question as a whole. It does not tell the listener which
part of the sentence is false.

## Saying What Is Not True

To say what is not true, use the prefix `mo-`. A prefix is a word part added to
the front of another word. Here, `mo-` means "not."

```txt
'al-es mo-barak'er
person-MAIN not-walk-ACTION
"The person does not walk."
```

The same pattern can give a short answer after a question:

```txt
mo-barak'er
not-walk-ACTION
"does not walk"
```

This is more specific than `mope`. It says exactly which action is being denied.

## Not with Describing Words

When a description uses `ka-`, put `mo-` before the whole `ka-` form.

```txt
kel-es mo-ka-kel'er
sky-MAIN not-blue-ACTION
"The sky is not blue."
```

The order matters here:

```txt
mo-ka-kel'er
not-blue-ACTION
"is not blue"
```

Think of `mo-ka-kel` as "not-blue," then `-'er` turns that description into the
main action-like word of the sentence.

## Not Correct

`gnar` can mean "yes" or "correct." To deny correctness, use `mo-gnar`.

```txt
mo-gnar
not-correct
"That is not right."
```

Use `mope` for a plain "no." Use `mo-gnar` when the point is that a statement,
answer, or action is incorrect.

## A Stronger Refusal: `pe!`

Early Hick also has `pe!`, an older refusal word. It is not the normal answer
for "no." It sounds sharper, more childish, teasing, or petulant depending on
the situation.

```txt
pe!
no!
"No!" / "I won't!"
```

For ordinary speech, use `mope`.

## Try It

Choose the best short answer or negative form.

1. Answer "no" as a whole sentence answer.

   ```txt
   'athid kel-es kakel'er?
   ```

1. Say "does not walk."

   ```txt
   barak'er
   ```

1. Say "is not blue."

   ```txt
   ka-kel'er
   ```

1. Say "that is not correct."

   ```txt
   gnar
   ```
