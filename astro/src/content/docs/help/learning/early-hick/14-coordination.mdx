## What You'll Learn

This lesson teaches how Early Hick joins equal pieces:

- `o ... o ru`, for "and";
- `o ... o 'a`, for "or";
- `o ... o ewes`, for "together with";
- how the joined group gets one sentence role ending.

## Mark Each Listed Item with `o`

Early Hick uses `o` to mark items in a list. The joining word comes after the
listed items.

```txt
'al'is o materok o ru
person-this LIST handler LIST and
"this person and the handler"
```

The word `o` does not mean "and" by itself. It marks each listed item. The
joining word `ru` tells you the list means "and."

That final joining word speaks for the whole list. It is also where Early Hick
puts the role ending for the joined group.

## And with `ru`

When the joined group does the action, put the doer ending `-el` on `ru`.

```txt
'al'is o materok o ru-el rismater-es ward'er
person-this LIST handler LIST and-DOER reed.boat-RECEIVER guide-ACTION
"This person and the handler guide the reed boat."
```

The people in the list do not each need `-el`. The ending goes on `ru` because
`ru` carries the role of the whole joined group.

When the joined group is the main noun or receiver, use `ru-es`.

```txt
materok-el 'al'is o rismater o ru-es ward'er
handler-DOER person-this LIST reed.boat LIST and-RECEIVER guide-ACTION
"The handler guides this person and the reed boat."
```

## Or with `'a`

Use `'a` when the joined items are alternatives, like English "or."

```txt
'al'is o materok o 'a-el rismater-es ward'er
person-this LIST handler LIST or-DOER reed.boat-RECEIVER guide-ACTION
"This person or the handler guides the reed boat."
```

The same role-ending pattern applies:

```txt
'a-el
or-DOER
"one of them as the doer"
```

```txt
'a-es
or-RECEIVER
"one of them as the receiver or main noun"
```

The older sense behind `'a` is "other" or "alternative." In ordinary sentences
like these, read it as "or."

## Together with `ewes`

Use `ewes` when the point is shared action or equal participation. It is closer
to "together with" than plain "and."

```txt
'al'is o Mari o ewes-es ward'er
person-this LIST Mari LIST together-MAIN travel-ACTION
"This person and Mari travel together."
```

Here `ewes-es` treats the listed people as one shared-action group.

The word `ewes` can also mean "together with" outside lists. In this pattern,
it is the final joining word for the whole group.

## And, Or, or Together?

Use `ru` for ordinary "and."

```txt
'al'is o materok o ru-el
person-this LIST handler LIST and-DOER
"this person and the handler" as doers
```

Use `'a` for alternatives.

```txt
'al'is o materok o 'a-el
person-this LIST handler LIST or-DOER
"this person or the handler" as doer
```

Use `ewes` when doing the action together matters.

```txt
'al'is o Mari o ewes-es
person-this LIST Mari LIST together-MAIN
"this person together with Mari" as one shared group
```
