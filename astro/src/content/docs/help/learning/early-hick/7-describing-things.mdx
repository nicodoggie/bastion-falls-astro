## What You'll Learn

This lesson teaches how Early Hick handles describing words:

- a describing word can come before a noun;
- a describing word can become action-like with `-'er`;
- many color words are built with `ka-`, meaning "like";
- place endings can show a change into a new state.

## Describing Words Before Nouns

Early Hick usually builds describing words with `ka-`, "like."
These describing words stand before the noun,
much like English adjectives.

```txt
ka'irek litor-es etal
firm-like hill-MAIN that
"that firm hill"
```

Here, `ka'irek` describes `litor`, "hill."

## Describing as an Action

Early Hick can also make a describing word act like a sentence action.

```txt
litor-es ka'irek'er
hill-MAIN firm-like-ACTION
"The hill is firm."
```

This is like saying "the hill firms" in a very literal beginner reading.

## Color Words

Early Hick often builds color words from familiar nouns.

| Early Hick | Word parts | English |
| ---------- | ---------- | ------- |
| `kakel`    | like-sky   | blue    |
| `kamar`    | like-blood | red     |
| `kathral`  | like-mist  | white   |
| `kagral`   | like-earth | brown   |

The prefix `ka-` means "like" or "similar to."

```txt
kakelrak kel
blue sky
"blue sky"
```

The longer ending `-rak` makes clear that the word is being used as a color.

## Becoming Something

The place ending `-las`, "into," can show a change into a new description.

```txt
kamar kel-es kakel-las
red sky-MAIN blue-INTO
"The red sky turns blue."
```

## Try It

Translate the sentence.

```txt
kel-es kakel'er
sky-MAIN blue-ACTION
```

<PopQuiz title="Answer">

```txt
"The sky is blue."
```

The describing word `kakel`, "blue," uses the action ending `-'er` to make a
complete sentence.

</PopQuiz>
