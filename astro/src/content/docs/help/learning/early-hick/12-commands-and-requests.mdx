## What You'll Learn

This lesson teaches common ways to ask someone to do something:

- direct commands with `-es`;
- stronger commands with `-'er-es`;
- softer requests with `naterlas`;
- negative commands with `mo-`.

## Direct Commands

Early Hick commands name the action as an event. The simplest command uses the
action stem plus `-es`.

<InterlinearGloss>
  <GlossToken source={"vinud"} gloss={"build"} />
  <GlossToken source={"-es!"} gloss={"COMMAND"} type="suffix" />
  <GlossTranslation>{"Build!"}</GlossTranslation>
</InterlinearGloss>

This is not a full sentence with a named doer. It is more like calling the
building event into action.

## Stronger or Clearer Commands

For a more explicit command, keep the action ending `-'er` and then add `-es`.
This can sound stronger, corrective, or more official.

<InterlinearGloss>
  <GlossToken source={"vinud"} gloss={"build"} />
  <GlossToken source={"-'er"} gloss={"ACTION"} type="suffix" />
  <GlossToken source={"-es!"} gloss={"COMMAND"} type="suffix" />
  <GlossTranslation>{"Do the building!"}</GlossTranslation>
</InterlinearGloss>

This form is useful when the speaker wants the action itself to be unmistakable.

## Naming the Listener

If the listener needs to be named, put that person after the command with the
doer ending `-el`.

<InterlinearGloss>
  <GlossToken source={"vinud"} gloss={"build"} />
  <GlossToken source={"-es,"} gloss={"COMMAND"} type="suffix" />
  <GlossToken source={"'al"} gloss={"person"} />
  <GlossToken source={"-'tan"} gloss={"that"} type="suffix" />
  <GlossToken source={"-el!"} gloss={"DOER"} type="suffix" />
  <GlossTranslation>{"Build, you!"}</GlossTranslation>
</InterlinearGloss>

With a name:

<InterlinearGloss>
  <GlossToken source={"vinud"} gloss={"build"} />
  <GlossToken source={"-es,"} gloss={"COMMAND"} type="suffix" />
  <GlossToken source={"Aigral"} gloss={"Aigral"} />
  <GlossToken source={"-el!"} gloss={"DOER"} type="suffix" />
  <GlossTranslation>{"Build, Aigral!"}</GlossTranslation>
</InterlinearGloss>

## Commands with a Receiver

When a command acts on a thing, the thing can come before the command word.

<InterlinearGloss>
  <GlossToken source={"materok"} gloss={"boat"} />
  <GlossToken source={"ka-"} gloss={"ADJ"} type="prefix" />
  <GlossToken source={"'il"} gloss={"good"} />
  <GlossToken source={"ward"} gloss={"guide"} />
  <GlossToken source={"-es!"} gloss={"COMMAND"} type="suffix" />
  <GlossTranslation>{"Guide the boat well!"}</GlossTranslation>
</InterlinearGloss>

The boat is not marked with `-es` here. In this command pattern, the action
word carries the command ending.

## Softer Requests

The word `naterlas` softens a command into a request. It means something like
"toward willingness."

<InterlinearGloss>
  <GlossToken source={"vinud"} gloss={"build"} />
  <GlossToken source={"-'er"} gloss={"ACTION"} type="suffix" />
  <GlossToken source={"-es"} gloss={"COMMAND"} type="suffix" />
  <GlossToken source={"naterlas"} gloss={"REQUEST"} />
  <GlossToken source={"'al"} gloss={"person"} />
  <GlossToken source={"-'tan"} gloss={"that"} type="suffix" />
  <GlossToken source={"-el"} gloss={"DOER"} type="suffix" />
  <GlossTranslation>{"\"Please build.\" / \"Would you be willing to build?\""}</GlossTranslation>
</InterlinearGloss>

This is gentler than a bare command because it asks the listener toward
willingness rather than simply calling the action.

## Negative Commands

To say "do not," put `mo-` before the action word.

<InterlinearGloss>
  <GlossToken source={"mo-"} gloss={"not"} type="prefix" />
  <GlossToken source={"vinud"} gloss={"build"} />
  <GlossToken source={"-'er!"} gloss={"ACTION"} type="suffix" />
  <GlossTranslation>{"Don't build!"}</GlossTranslation>
</InterlinearGloss>

For a more formal or explicit negative command, Early Hick can keep the command
event and add a negative action word:

<InterlinearGloss>
  <GlossToken source={"vinud"} gloss={"build"} />
  <GlossToken source={"-'er"} gloss={"ACTION"} type="suffix" />
  <GlossToken source={"-es"} gloss={"COMMAND"} type="suffix" />
  <GlossToken source={"mo-"} gloss={"not"} type="prefix" />
  <GlossToken source={"'er"} gloss={"ACTION"} />
  <GlossToken source={"'al"} gloss={"person"} />
  <GlossToken source={"-'tan"} gloss={"that"} type="suffix" />
  <GlossToken source={"-el"} gloss={"DOER"} type="suffix" />
  <GlossTranslation>{"You are not to build."}</GlossTranslation>
</InterlinearGloss>

## Try It

Translate each command or request.

1. `vinud-es!`
1. `vinud'er-es!`
1. `vinud-es, Aigral-el!`
1. `vinud'er-es naterlas 'al'tan-el`
1. `mo-vinud'er!`

<PopQuiz title="Answers">

1. `vinud-es!`

   ```txt
   build-COMMAND
   "Build!"
   ```

1. `vinud'er-es!`

   ```txt
   build-ACTION-COMMAND
   "Do the building!"
   ```

1. `vinud-es, Aigral-el!`

   ```txt
   build-COMMAND Aigral-DOER
   "Build, Aigral!"
   ```

1. `vinud'er-es naterlas 'al'tan-el`

   ```txt
   build-ACTION-COMMAND REQUEST person-that-DOER
   "Please build." / "Would you be willing to build?"
   ```

1. `mo-vinud'er!`

   ```txt
   not-build-ACTION
   "Don't build!"
   ```

</PopQuiz>
