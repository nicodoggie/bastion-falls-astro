## What You'll Learn

This lesson teaches beginner-safe ways to answer questions:

- answer a "who, what, where" question with the missing word;
- keep the same sentence role ending when the answer needs one;
- answer a yes/no question with `gnar`, `nar`, `mope`, a full sentence, or a short echo;
- use `mo-`, the "not" prefix, when you need to say exactly what is not true.

## Answer the Missing Part

Some questions ask for a missing noun, person, place, time, or manner. In
English class, these are often called "who, what, where, when, and how"
questions.

Early Hick question words take the same kind of role endings as ordinary nouns.
If the question asks for the receiver or main noun, the question word can take
the main/receiver ending `-es`.

```txt
'aka-es materok-el ward'er?
what-RECEIVER handler-DOER guide-ACTION
"What does the handler guide?"
```

A short answer can give the missing receiver with the same ending:

```txt
rismater-es
reed.boat-RECEIVER
"the reed boat"
```

A fuller answer repeats the whole sentence:

```txt
materok-el rismater-es ward'er
handler-DOER reed.boat-RECEIVER guide-ACTION
"The handler guides the reed boat."
```

## Answer Who Did It

If the question asks for the doer, the answer can use the doer ending `-el`.

```txt
'alis-el rismater-es ward'er?
who-DOER reed.boat-RECEIVER guide-ACTION
"Who guides the reed boat?"
```

Short answer:

```txt
materok-el
handler-DOER
"the handler"
```

The role ending matters because it tells the listener how the answer fits into
the question.

## Answer Yes or No

Early Hick can ask a yes/no question with `'aka thid`, "is it true?", or the
shorter question word `'athid`.

```txt
'athid kel-es kakel'er?
IS.IT.TRUE sky-MAIN blue-ACTION
"Is the sky blue?"
```

The short answer `gnar` means "yes" or "correct." It is the ordinary answer when
someone asks whether a statement is true.

```txt
gnar
yes
"Yes."
```

In familiar or quick speech, `nar` works more like English "yup" or "yeah."

```txt
nar
yup
"Yup."
```

The safest beginner answer is a full sentence:

```txt
kel-es kakel'er
sky-MAIN blue-ACTION
"The sky is blue."
```

In quick speech, a short echo can answer by repeating the important sentence
word:

```txt
kakel'er
blue-ACTION
"It is blue."
```

## Answer No

The default single-word answer for "no" is `mope`.

```txt
mope
no
"No."
```

`mope` answers the question. To say exactly what is not true, negate the word
being denied. Use `mo-`, the "not" prefix.

```txt
'athid 'al-es barak'er?
IS.IT.TRUE person-MAIN walk-ACTION
"Does the person walk?"
```

Full negative answer:

```txt
'al-es mo-barak'er
person-MAIN not-walk-ACTION
"The person does not walk."
```

Short negative echo:

```txt
mo-barak'er
not-walk-ACTION
"does not walk"
```

A transparent answer like `mo-gnar`, "not correct," is possible when the answer
means "that is not right."

```txt
mo-gnar
not-correct
"That is not right."
```

For describing sentences, `mo-` comes before the `ka-` form:

```txt
kel-es mo-ka-kel'er
sky-MAIN not-blue-ACTION
"The sky is not blue."
```

## Try It

Answer each question with a short answer.

1. What does the handler guide?

   ```txt
   'aka-es materok-el ward'er?
   ```

1. Who guides the reed boat?

   ```txt
   'alis-el rismater-es ward'er?
   ```

1. Does the person walk? Answer "no."

   ```txt
   'athid 'al-es barak'er?
   ```

1. Is the sky blue? Answer with the ordinary word for "yes."

   ```txt
   'athid kel-es kakel'er?
   ```
