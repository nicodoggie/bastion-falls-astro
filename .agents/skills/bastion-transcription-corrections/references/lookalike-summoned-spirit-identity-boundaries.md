# Lookalike Summoned Spirit Identity Boundaries

Use when a note/transcript keeps merging a mundane person with a summoned spirit, astral/dream form, disguise, or transformed body because the spirit borrows the person's appearance.

## Pattern

1. Check the active note and same-campaign continuity for the spell/item scene that created the lookalike.
2. Patch the active note wherever later recognition/reunion scenes carry the confusion forward.
3. Name both sides explicitly:
   - `mundane <Person>` for the real person.
   - `Luana-like fey spirit`, `Arcadia-like manifestation`, etc. for the summoned spirit.
4. State the negative boundary in plain language: the spirit is **not** the person's astral self, younger self, disguise, or transformed body.
5. If an item effect was applied in the spirit scene, say it applied to the spirit, not to the mundane person.
6. Strengthen shared correction rules in both the character/person rule and the spell/item/mechanics rule, because future models may enter through either concept.

## Example: Luana-like Fey Spirit

For the 2026-06-21 / 2026-06-27 Vengeful cleanup, Lime's creative _Summon Fey_ use shaped a separate summoned fey spirit to look like Luana Victorique Dubreuil. Henson/Miya/Lime later recognizing real Luana should not imply that the earlier spirit was mundane Luana. Essence of Nymph belonged to the spirit support scene; do not treat the intimate-contact memory as something mundane Luana personally experienced.
